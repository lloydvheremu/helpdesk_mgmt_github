This module is the shared base of the GitHub modules in this repository.
On its own it adds no menu. Install one of the modules that use it:

-  ``helpdesk_mgmt_github``: GitHub issues become Helpdesk tickets (OCA
   `Helpdesk
   Management <https://github.com/OCA/helpdesk/tree/19.0/helpdesk_mgmt>`__).
-  ``project_github``: GitHub issues become project tasks.

It provides:

-  A small client for the GitHub REST API. It pages through the issues
   of a repository, skips pull requests and turns rate limits, bad
   tokens and timeouts into clear error messages.
-  One GitHub access token for the whole database, in the general
   settings.
-  A *GitHub Login* on users, so issue assignees can be matched to Odoo
   users.
-  Two mixins that hold the sync logic, so each module only maps an
   issue to its own records:

   -  ``github.issue.sync.mixin``, for the record linked to a repository
      (a Helpdesk team, a project): repository fields, *Sync now*, the
      scheduled sync and error logging in the chatter.
   -  ``github.issue.mixin``, for the records that mirror an issue (a
      ticket, a task): issue id, number, URL, state and last sync time.

Installation
============

This module is installed automatically with ``helpdesk_mgmt_github`` or
``project_github``. To install it:

1. Clone this repository and add the repository folder to the Odoo
   ``addons_path``. Each module is a folder of the repository.
2. Install the Python dependency: ``pip install requests``.

Configuration
=============

To configure this module, you need to:

1. Create a GitHub `fine-grained personal access
   token <https://github.com/settings/personal-access-tokens>`__ with
   read-only access to *Issues* on the repositories you want to sync.
   For public repositories the token is optional, but GitHub then allows
   only 60 requests per hour.

2. Go to *Settings > General Settings > Integrations* and paste the
   token in *GitHub Access Token*. It is stored as a system parameter
   that only administrators can read.

   .. image:: https://raw.githubusercontent.com/lloydvheremu/helpdesk_mgmt_github/main/github_issue_sync/static/description/usage_settings_token.png
      :alt: Token setting

3. Optional: open a user (*Settings > Users & Companies > Users*), go to
   the *Preferences* tab and set the *GitHub Login*. Issues assigned to
   that GitHub account are then assigned to this user. The login is
   unique, ignoring case.

   .. image:: https://raw.githubusercontent.com/lloydvheremu/helpdesk_mgmt_github/main/github_issue_sync/static/description/usage_user_github_login.png
      :alt: GitHub Login on the user

Development
===========

To sync GitHub issues into another model, inherit the two mixins and map
an issue to your record. For example, for a model ``my.board`` whose
records hold ``my.card`` records:

.. code:: python

   class MyCard(models.Model):
       _name = "my.card"
       _inherit = ["my.card", "github.issue.mixin"]

       _github_issue_unique = models.Constraint(
           "UNIQUE(board_id, github_issue_id)",
           "This GitHub issue is already linked to a card of this board.",
       )


   class MyBoard(models.Model):
       _name = "my.board"
       _inherit = ["my.board", "github.issue.sync.mixin"]  # my.board uses mail.thread

       _github_record_model = "my.card"
       _github_record_link_field = "board_id"

       def _github_record_values(self, issue, record, cache):
           values = super()._github_record_values(issue, record, cache)
           values["name"] = issue["title"]
           return values

Then add a scheduled action that runs ``model._cron_github_sync()`` on
``my.board``, and a *Sync now* button that calls ``action_github_sync``.

The tests mock GitHub, so they work offline. The helpers in
``tests/github_mocks.py`` build fake API responses for the tests of the
other modules too.

Known issues / Roadmap
======================

-  Replace the client, token and GitHub logins with OCA
   `github_connector <https://github.com/OCA/interface-github>`__ once
   it is available for Odoo 19.0. It is not merged for 19.0 yet.
-  One token for the whole database, not one per repository or per user.
-  Send changes made in Odoo back to GitHub (two-way sync, planned for
   v2).
-  Webhooks, so updates arrive immediately instead of with the next run.
