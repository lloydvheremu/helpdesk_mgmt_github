This module imports the issues of a GitHub repository as tickets of the
OCA `Helpdesk
Management <https://github.com/OCA/helpdesk/tree/19.0/helpdesk_mgmt>`__
module (``helpdesk.ticket``), and keeps them up to date with a scheduled
job.

A Helpdesk team is linked to one GitHub repository. Every issue becomes
a ticket of that team and is updated on later runs. Pull requests are
skipped.

+--------------------+------------------------------------------------+
| GitHub             | Helpdesk ticket                                |
+====================+================================================+
| Title              | Title                                          |
+--------------------+------------------------------------------------+
| Body               | Description (plain text). A placeholder is     |
|                    | used when the body is empty, because the       |
|                    | description is required                        |
+--------------------+------------------------------------------------+
| Labels             | Tags (reused by name, created when missing)    |
+--------------------+------------------------------------------------+
| Assignees          | Assigned user: the first assignee whose GitHub |
|                    | Login matches a user allowed on the team       |
+--------------------+------------------------------------------------+
| Open / reopened    | The team's first open stage, or the stage      |
|                    | chosen on the team                             |
+--------------------+------------------------------------------------+
| Closed             | The team's first closed stage, or the stage    |
|                    | chosen on the team                             |
+--------------------+------------------------------------------------+
| Number, URL, state | Read-only GitHub tab on the ticket             |
+--------------------+------------------------------------------------+

GitHub is the source of truth: changes made in Odoo to the title,
description, tags and assignee are overwritten the next time the issue
changes on GitHub. Creating tickets does not notify the assignee.

Installation
============

To install this module, you need to:

1. Install the OCA `Helpdesk
   Management <https://github.com/OCA/helpdesk/tree/19.0/helpdesk_mgmt>`__
   module (``helpdesk_mgmt``, branch ``19.0``).
2. Clone this repository and add the repository folder to the Odoo
   ``addons_path``. Each module is a folder of the repository, and this
   module needs ``github_issue_sync`` from the same repository.
3. Install the Python dependency: ``pip install requests``.
4. Update the apps list and install *Helpdesk GitHub Sync*.

When you upgrade from version 19.0.2, ``github_issue_sync`` is installed
during the upgrade. The token you saved and the GitHub logins of your
users are kept.

Configuration
=============

To configure this module, you need to:

1. Set the GitHub access token and, optionally, the *GitHub Login* of
   your users. Both come from the *GitHub Issue Sync*
   (``github_issue_sync``) module: see its configuration section. The
   token is in *Settings > General Settings > Integrations*.

Usage
=====

To link a team to a repository:

1. Go to *Helpdesk > Configuration > Teams* and open a team. You must be
   a Helpdesk manager.

2. Open the *GitHub* tab, enter the repository as ``owner/name`` and
   tick *Sync with GitHub*. Optionally choose the stage for open issues
   and the stage for closed issues. Without a choice, the team's first
   open and first closed stages are used.

   .. image:: https://raw.githubusercontent.com/lloydvheremu/helpdesk_mgmt_github/main/helpdesk_mgmt_github/static/description/usage_team_github_tab.png
      :alt: GitHub tab of the team

3. Click *Sync now*, or wait for the hourly scheduled action *Helpdesk:
   Sync GitHub issues*. A notification shows how many tickets were
   created and updated.

   .. image:: https://raw.githubusercontent.com/lloydvheremu/helpdesk_mgmt_github/main/helpdesk_mgmt_github/static/description/usage_sync_now.png
      :alt: Sync now

4. The issues are now in *Helpdesk > Tickets*, with their labels as
   tags. This is what the same issues look like on GitHub, listed with
   the ``gh`` command line tool:

   .. image:: https://raw.githubusercontent.com/lloydvheremu/helpdesk_mgmt_github/main/helpdesk_mgmt_github/static/description/usage_github_issue_list.png
      :alt: Issues on GitHub

   .. image:: https://raw.githubusercontent.com/lloydvheremu/helpdesk_mgmt_github/main/helpdesk_mgmt_github/static/description/usage_tickets.png
      :alt: Imported tickets

5. Open a ticket and use its *GitHub* tab to see the issue number, a
   link to the issue, its state and the time of the last sync. The
   ticket name, description and tags come from the title, body and
   labels of the issue (here issue 31):

   .. image:: https://raw.githubusercontent.com/lloydvheremu/helpdesk_mgmt_github/main/helpdesk_mgmt_github/static/description/usage_github_issue_view.png
      :alt: Issue 31 on GitHub

   .. image:: https://raw.githubusercontent.com/lloydvheremu/helpdesk_mgmt_github/main/helpdesk_mgmt_github/static/description/usage_ticket_github_tab.png
      :alt: GitHub tab of the ticket

Running the sync again never creates duplicates, even if a ticket was
archived. If GitHub returns an error (bad token, rate limit, repository
not found, timeout), it is posted in the team's chatter and the last
sync time is not advanced, so the next run fetches the same issues
again.

The screenshots show a test database with the public repository
``lloydvheremu/industry_insight``.

Development
===========

Run the linters with `pre-commit <https://pre-commit.com>`__, from the
repository folder:

.. code:: sh

   pre-commit install
   pre-commit run --all-files

Run the tests on a throwaway database. They mock GitHub, so they work
offline:

.. code:: sh

   odoo-bin -d test_github_sync -i helpdesk_mgmt_github --test-tags /github_issue_sync,/helpdesk_mgmt_github --stop-after-init

The same linters and tests run on GitHub Actions for every push and pull
request, in the OCA CI image for Odoo 19.0.

Known issues / Roadmap
======================

-  Send changes made in Odoo back to GitHub (two-way sync, planned for
   v2).
-  Webhooks, so updates arrive immediately instead of with the next run.
-  Set the ticket's customer (``partner_id``) from the GitHub author.
-  A ticket has a single assigned user, so only one GitHub assignee is
   used.
-  Render the Markdown of issue bodies and import issue comments.
-  Sync GitHub Projects boards (GraphQL API).
